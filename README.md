# School Flow

A polished, offline-friendly daily planner built around Colts Neck High School's 2026–27 A–G rotating block schedule.

## Features
- Automatic A–G day calculation anchored to Sept. 28, 2026 = G day
- School closures do not advance the rotation
- Weekends included for personal plans
- Day, week, month, and full schedule views
- Q1–Q4 schedule changes for Micro/Macro and PE/Health
- Planner items stored locally in the browser
- Responsive and installable as a lightweight PWA

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Hosting
Works on GitHub Pages, Vercel, Netlify, or any static host.
